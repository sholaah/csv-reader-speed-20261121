A faster drop-in for make.fun's csv-reader 1.0.0 that answers exactly as it does on every case. `solve.js` reads a broken CSV text once, left to right, reproducing csv-reader's exact `{columns, rows, errors}` — including its stray-CR, unterminated-quote, quote-junk, short-row and long-row errors — while running several times faster: plain records are taken in one slice + split, quoted fields jump from quote to quote with `indexOf`, and unquoted fields walk a tight character loop that only slices at delimiters.

## Run it

```sh
node main.ts
```

`main.ts` reads every case from `/input/cases.json`, answers each one alone with `run()` from `solve.js`, and writes `/output/answers.json`. Outside a container, `MAKEFUN_INPUT_DIR` and `MAKEFUN_OUTPUT_DIR` stand in for `/input` and `/output`. Node 22 or later, no dependencies, no network.
